# Day 26 - Merge Sort

Today I practiced Merge Sort and array merging techniques.

Programs included:

- merge_sort.c
- merge_two_arrays.c
- merge_sort_descending.c
- display_array.c

Concepts practiced:

- Divide and Conquer
- Recursive sorting
- Merging sorted arrays
- Ascending and descending sorting

Merge Sort is a stable sorting algorithm with a time complexity of O(n log n).
