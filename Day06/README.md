# Day 06 - Recursion Programs

Today I practiced recursion to understand how functions call themselves and how the call stack works.

Programs included:

- factorial_recursion.c
- fibonacci_recursion.c
- sum_of_digits_recursion.c
- power_recursion.c

Concepts practiced:

- Base case and recursive case
- Breaking problems into smaller subproblems
- Understanding function call flow
- Stack behavior in recursion

Recursion is important for advanced problem solving and interview preparation.
