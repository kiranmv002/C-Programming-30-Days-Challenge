# Day 22 - Stack and Queue Using Linked List

Today I implemented Stack and Queue using Linked List.

Programs included:

- stack_using_ll.c
- queue_using_ll.c
- display_stack.c
- display_queue.c

Concepts practiced:

- Dynamic memory allocation
- Stack implementation using linked list
- Queue implementation using linked list

This approach removes the fixed-size limitation of array-based implementations.
