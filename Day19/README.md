# Day 19 - Dynamic Memory Allocation

Today I practiced dynamic memory allocation in C using malloc, calloc, realloc, and free.

Programs included:

- malloc_example.c
- calloc_example.c
- realloc_example.c
- free_memory.c

Concepts practiced:

- Allocating memory dynamically
- Difference between malloc and calloc
- Resizing memory using realloc
- Freeing memory using free()

Dynamic memory is important for efficient memory usage and advanced data structures.
