# Day 05 - Pointer Practice

Today I focused on understanding pointers and memory handling in C.

Programs included:

- swap_using_pointers.c
- pointer_arithmetic.c
- array_using_pointer.c
- malloc_example.c

Concepts practiced:

- Passing variables by reference
- Pointer dereferencing
- Pointer arithmetic
- Dynamic memory allocation using malloc()
- Freeing allocated memory

Pointers are important to understand how memory works internally in C.
